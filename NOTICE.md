# Data attribution

This project uses the public **Criteo Uplift Prediction Dataset** as a
reproducible proxy for a social-commerce exposure decision. The dataset was
published by Criteo AI Lab and is available under **CC BY-NC-SA 4.0**. The
repository does not redistribute the raw archive; `scripts/fetch_hf_sample.py`
retrieves a small sample from the Hugging Face dataset server.

Source: <https://ailab.criteo.com/criteo-uplift-prediction-dataset/>

The project code and written analysis are released under the MIT License in
this repository. The dataset licence remains separate and applies to the
dataset and any derived data.
